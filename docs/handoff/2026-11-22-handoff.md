## 5. 固件配置与实现边界

| 配置项 | 当前默认值 | 修改位置 |
| --- | --- | --- |
| MCU | STM32H743VGT6 | `2017H.ioc` |
| DDS 输出通道 | 芯片 CH2 | `Core/Inc/dds_config.h` |
| DDS 启动频率 / 幅度码 / 相位 | 100000Hz / 512 / 0° | 同上 |
| DDS 时钟计算依据 | 25MHz × 20 = 500MHz | 同上；实际时钟及锁定仍需仪器确认 |
| ADC 输入 | 芯片 AIN1 对 AINCOM | `Core/Inc/adc_config.h` |
| ADC PGA / 数据率 | 1 / 100SPS | 同上 |
| ADC 软件参考电压 | 3000000µV，即 3000mV | 同上，**尚待实测确认** |
| ADC 输入缓冲 | 关闭 | `Core/Src/ads1256.c` |
| ADC 串口显示间隔 | 200ms | `Core/Inc/adc_config.h` |

实现情况：

- DDS 使用 SPI 写寄存器，未实现寄存器回读及 PLL 锁定检测。串口 `OK` 说明软件写入过程返回成功，不能单独证明外设输出正确。
- ADC 初始化包含硬件复位、配置寄存器回读、芯片 ID 检查和自校准，期望 ID 为 3；这也不等于完成模拟精度校准。
- ADC DRDY 中断只置标志并计数，SPI 读取和串口打印在主循环执行。24 位有符号码以 64 位中间结果换算电压。
- ADC 初始化后在后台采样；`ADC ON/OFF` 只控制连续串口显示，不控制 ADC 供电或后台采集。
- 200ms 显示的是最新一个样本，不是期间样本的平均值；没有实现高速无丢样缓存、文件记录或多通道轮询。
- SPI 出错后有错误提示，可排查后手动 `ADC INIT` 恢复；ADC 不可用时仍可操作 DDS。
- 串口设置主要保存在 RAM，复位后恢复配置头文件中的默认值，没有持久化存储。

真实日志节选：

```text
ADC AIN1 RAW=1906169 U=1363.398mV AGE=7ms N=1600 SAT=0
ADC AIN1 RAW=1905927 U=1363.225mV AGE=8ms N=2019 SAT=0
ADC AIN1 RAW=1906223 U=1363.436mV AGE=4ms N=2299 SAT=0
```

这批显示值的最大与最小相差约 **0.211mV**，仅描述所贴样本的变化范围，不是 ADC 的精度或系统噪声指标。`N` 每 200ms 左右增加约 20，与默认 100SPS 相符；`AGE` 约 1～10ms，说明显示时有近期读入的样本。

`SAT=0` 只表示 ADC 数字结果没有到正负满量程端点，不能证明放大器、乘法器或滤波器没有饱和。`AGE` 超过 1s 时软件会标记数据过期。

如果放大器的 1.22V 指 **Vpp**，则本次幅度比约为 `1.22 / 0.274 = 4.45`；如果指峰值或 RMS，这个增益计算不适用。

### 8.2 电压换算与参考电压问题

固件计算式为：

```text
U = RAW × 2 × VREF / (8388608 × PGA)
```

VREF 使用什么单位，U 就得到相同单位。当前默认 VREF=3.0V、PGA=1；例如 RAW=1906169 时显示约 1.363398V，代码与日志在数值上自洽。**数值自洽不能证明实际输入就是该电压。**

现有资料存在不一致：模块原理图标注 REF2930（3.0V），厂家示例却按约 2.5V 换算。仓库现有 `README_ADS1256.md` 还记录了 3.0V 与芯片额定参考范围的冲突，接手时需要结合实板版本和原始手册确认。实际参考电压尚无实测结论。

必须测量 VREFP 对 VREFN 的真实电压，不能根据哪个参数能“凑出目标读数”来选择参考值。即使从 3.0V 改为 2.5V，也只是将同一 RAW 的换算电压乘以 5/6，不能直接解释此前未明确节点的 2.409V。

如果万用表与 ADC 在**同一时刻、同一输入端对同一参考地**分别测得 2.409V 和约 1.363V，需要先排查通道映射、参考电压、接地和换算。前级放大器增益不能单独解释同一节点两个仪器的读数不一致。

- [ ] 确认后再固化默认通道与 `ADC_REFERENCE_UV`，避免重启恢复错误配置。

验收：能明确端子→芯片通道映射，已知直流输入与 ADC 的多点差异有完整记录，并能据仪器及系统精度要求判断是否可接受。

### P1：补齐模拟前端参数并验证平方律

需要补齐：放大器型号与供电、实际增益、乘法器型号、两路输入接法、比例系数、直流偏置，以及低通滤波器截止频率和直流增益。**目前没有证据确认乘法器型号，不能默认它是 AD633 或直接套用某型号的比例常数。**

保持频率 100kHz，先确认每档放大器输出未削顶，再按下表测试。每步等待滤波器输出稳定，至少记录 10 次串口显示及同点万用表读数；稳定时间以实际滤波器为准。

| 步骤 | DDS 设置 | 应记录内容 |
| --- | --- | --- |
| 1 | `SET 100kHz 0 0` | 无激励档基线 U0、放大器残余输出、滤波器直流电压 |
| 2 | `AMP 256` | DDS 实测 Vpp、放大器实测 Vpp、滤波器读数 U1 |
| 3 | `AMP 512` | 相同测量项目及滤波器读数 U2 |
| 4 | 在确认前端量程后决定是否测试 `AMP 1023` | 检查大信号下是否压缩、削顶或偏离平方律 |

理想条件下，两路输入为相同的零偏置正弦，且前后级保持线性时：

```text
U滤波 = U0 + K × Vpp² / 8
```

这里 Vpp 指乘法器输入正弦的峰峰值，K 包含乘法器比例系数和后级直流增益。如果比较的是 DDS 输出，还要计入前级放大器增益的平方。

只有当乘法器输入 Vpp 实测翻倍时，才预期去除基线后的直流量约变为四倍：`(U2−U0)/(U1−U0) ≈ 4`。U1−U0 接近噪声、输入存在直流偏置、两路输入不一致或电路削顶时，该简单比较不成立。

验收：保留零点及多个非零幅度点的完整数据，确认输出随实际输入幅值的平方变化，并明确有效测量范围。

- [ ] 根据实测建立 `U滤波−U0` 与输入幅值平方的标定曲线，明确频率、负载及有效范围。
- [ ] 确定需要输出的是输入 Vpp、峰值、RMS 还是功率；功率还需确定负载与测量参考面。
