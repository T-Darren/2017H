# ADS1256：H743 检波后电压采集

本工程用 AD9959 产生激励信号，用 ADS1256 采集乘法器平方检波、低通滤波后的电压。ADC 默认读取 AIN1 对 AINCOM 的单端电压，数据率 100 SPS，PGA 增益 1，输入缓冲关闭。模块原理图中 AINCOM 已接 AGND。

## 接线

| ADS1256 模块 | H743 / 电源 | 功能 |
|---|---|---|
| +5V | 稳定的 5V 电源 | 模块供电；数字接口为 3.3V |
| 两处 GND | H743 GND、电源 GND | 共地 |
| SCLK | PC10 | SPI3_SCK，AF6 |
| DOUT | PC11 | SPI3_MISO，AF6 |
| DIN | PC12 | SPI3_MOSI，AF6 |
| CS | PC9 | GPIO 输出，空闲高 |
| DRDY | PB0 | 上拉输入，EXTI0 下降沿 |
| SYNC / PDWN | PC6 | GPIO 输出，正常高 |
| RST / RESET | PC7 | GPIO 输出，正常高，初始化时拉低复位 |
| D0～D3 | 不连接 | 辅助 GPIO，不是 SPI 数据线 |
| IN1 / AIN1 | 低通滤波器输出 | 默认被测电压输入 |
| AGND | 低通滤波器信号地 | 模拟信号回路 |

信号接入前确认滤波器输出相对 AGND 位于 0V 至 ADC 实际 AVDD 之间。平方检波电路若使用双电源，需确认其输出没有负压或过大的偏置。ADC 的“有符号结果 / 差分量程”不表示单个输入脚可以直接承受负电压。

原厂接线说明使用 F1 标准外设库和 GPIO 模拟 SPI，不能把其中 PC10/PC11/PC12 的软件用途直接套到 H7 硬件 SPI。这里采用的是 SPI3 的实际硬件复用关系。

## CubeMX 配置

已经在 2017H.ioc 中配置，并使用本机 STM32CubeMX 6.16.1 生成初始化代码：

- SPI3：全双工主机、8 位、MSB first、CPOL Low、CPHA 2 Edge（Mode 1）。
- SPI3 内核时钟 80MHz，64 分频，SCLK 为 1.25MHz；软件 NSS，关闭 NSS pulse。
- PC9/PC6/PC7：推挽输出，初始高电平。
- PB0：GPIO_EXTI0，下降沿，上拉，中断优先级 6。
- 原 DDS 的 SPI1 和 USART2 的 PA2 TX / PD6 RX 保留；串口参数 115200、8N1、无流控。

Core/Src/main.c 的应用调用放在 USER CODE 区域，驱动源码在顶层 CMakeLists.txt 中添加，后续 CubeMX 重新生成时可以保留。

## 串口操作

每条命令以回车或换行结束，大小写均可。上电自动初始化 ADC；未连接或通信失败时会输出错误，DDS 控制仍可使用。

```text
ADC STATUS
ADC READ
ADC ON
ADC OFF
```

- `ADC STATUS`：显示芯片 ID、配置、校准状态及系数、读取次数、DRDY 中断次数和数据年龄。
- `ADC READ`：显示最新一个有效采样，包含 RAW 原始码、U 电压及校准前的 U_UNCAL 电压（mV）。
- `ADC ON`：每 200ms 显示一次最新采样；ADC 本身仍按设置的数据率转换。
- `ADC OFF`：停止连续串口显示，后台转换和读取继续。
- `ADC INIT`：硬件复位、重新配置、寄存器回读验证和自校准；停止连续显示。

成功初始化时应看到 `ADC OK ID=3`。例如下面只展示输出格式，不代表实机测量结果：

```text
ADC AIN1 RAW=16132 U=0.000mV U_UNCAL=9.615mV AGE=0ms N=123 SAT=0
```

`SAT=1` 表示 ADC 数字结果到达量程端点。`STALE` 或 `no fresh sample` 表示超过 1 秒没有新样本，不应继续当作当前电压使用。SPI 出错后需排查接线并发送 `ADC INIT`。

## 调整参数

```text
ADC CH 1
ADC GAIN 1
ADC RATE 100
ADC VREF 2500
ADC ON
```

- `ADC CH 0..7`：选择一个单端输入，对 AINCOM 测量；当前不做多通道轮询。
- `ADC GAIN 1/2/4/8/16/32/64`：调整 PGA。先以增益 1 验证电压，再根据检波后信号范围选择增益。
- `ADC RATE` 支持整数 SPS：10、15、25、30、50、60、100、500、1000、2000、3750、7500、15000、30000。
- 改通道、增益、数据率时会自校准并停止串口连续显示，之后重新发送 `ADC ON`。
- `ADC VREF <mV>` 只调整软件电压换算，不改变模块参考电压；参数重启后恢复 adc_config.h 中的默认值。

**当前实板参考电压按 2.5V 配置。** 2026-11-25 用户确认模块参考为 2.5V、VREFP 接 2.5V；按模块 VREFN 接地的连接，现将 `ADC_REFERENCE_UV` 默认值改为 `2500000UL`。提供的资料原理图标注 REF2930（3.0V），与当前实板及厂家示例的 2.5V 换算不一致，因此不再沿用先前的 3.0V 软件默认值。参考电压实际指 VREFP 与 VREFN 之差，更换模块时应重新核实。

旧固件无需立即重烧即可发送 `ADC VREF 2500`，再发送 `ADC STATUS` 和 `ADC READ` 检查；这个命令只改变 RAM 中的软件换算，重启后仍恢复旧固件的默认值。下载此次修改后的固件，才能在上电时默认采用 2500mV。

本次用户提供 `RAW=612506`，旧 3.0V 配置显示 438.098mV；相同 RAW 按 2.5V 换算应显示 365.082mV。用户同时报告万用表输入读数为 356mV，仍相差约 9.082mV（2.55%），需要保持输入稳定后同点复测，并继续确认输入通道、AINCOM/AGND、实际差分参考值和测量误差。修改参考配置不等于完成全链路精度验证。

原始电压换算使用：

```text
U_UNCAL = RAW × 2 × VREF / (8388608 × PGA)
```

### 2026-11-27 直流校准

默认启用本次实测得到的线性补偿。以输入接 AGND 时约 9.615mV 的零点，以及万用表 500mV 对应的 ADC 平均值 507.603625mV 为校准点：

```text
U(mV) = (U_UNCAL(mV) - 9.615) × 1.004039
```

`Core/Inc/adc_config.h` 中保存默认 2.5V 参考、`ADC_CALIBRATION_OFFSET_UV=9615` 和 `ADC_CALIBRATION_GAIN_PPM=1004039`。计算采用 64 位整数中间值，正负数均四舍五入至微伏，保留负的小读数，不将其截断为零。

只有 AIN1、PGA=1、100SPS、软件参考 2500mV 同时满足时才应用这组系数，`ADC STATUS` 显示 `CAL=ON`。改变其中任一参数会自动停用补偿并显示 `CAL=OFF`，此时 `U` 与 `U_UNCAL` 相同；恢复全部条件后重新启用。可在配置文件中设置 `ADC_CALIBRATION_ENABLED=0` 并重新构建来关闭补偿。`ADC INIT` 自校准之后仍按当前设置判断是否启用这组固定补偿，重新初始化、断电或改变接线后需复核零点。

独立验证点：万用表 202mV 对应 ADC 平均值 209.695149mV，按此公式回算约 200.888mV，仍相差 -1.112mV（约 -0.55%）。本次是初步直流校准，验证范围约 0～500mV，其他电压范围未验证。补偿不改变 RAW，也不对采样做平滑或平均。2026-11-27 用户反馈此前 40MHz 检波采集时的抖动已消除；具体处理原因未记录，本次未独立硬件复测，也未据此确认抖动与直流校准之间存在因果关系。

默认 100 SPS 适合先验证检波后的缓慢变化电压。具体数据率应结合低通截止频率和所需响应速度调整。串口每秒只显示 5 次最新值，没有对中间样本求平均，也不提供高数据率下的无丢样记录。原始 100kHz 载波由前端检波，不由本 ADC 直接还原。

这里的 U 是按 CAL 状态决定是否补偿的滤波器输出电压，U_UNCAL 是仅按参考电压和 PGA 换算的电压。要反推原高频信号的峰值或有效值，还需要乘法器比例系数、前端增益和直流偏置的实测标定，当前不自动进行平方根换算。

## 验证与烧录

1. 按表接好数字控制线、电源和公共地。
2. 先让 IN1 接 AGND，确认 `ADC STATUS` 中 ID=3，`ADC ON` 显示接近零的电压和持续增加的 N。
3. 再输入用万用表确认过的已知直流电压，核对电压换算和参考电压设置。
4. 最后接入低通滤波器输出，观察电压随激励变化。
